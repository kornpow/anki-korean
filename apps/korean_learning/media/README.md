# Media collection

The committed collection manifests describe the original 50-image research pool and two ten-image review samples. `sample-10` contains IDs #1–10; `sample-20` contains #11–20. Records preserve source URLs, authors, licenses, dimensions, checksums, learning targets, and—where prepared—translations and contextual framing.

Follow [app setup](../README.md) to restore photographs and build the review pages. Files in `feedback/` contain personal decisions and notes and must remain untracked. The app's served static directory is `starter-50/`; feedback lives outside it.

The collection includes historical photos and prices. Translations describe visible text and are not current travel, product, legal, or safety guidance. Small print is explicitly outside the selected translation when it has not been transcribed.
