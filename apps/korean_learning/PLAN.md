# Korean Language Learning Tool Plan

Draft for iteration. Updated October 1, 2026.

Build a Korean learning tool organized around useful themes and personal interests. Learn from everyday Korean across menus, signs, labels, notices, messages, and media. Connect vocabulary, real-world reading, and writing, with dedicated flashcard and verb practice available independently.

## Confirmed priorities

- Learn themed word lists instead of an assortment of unrelated vocabulary.
- Make typing Korean characters with a keyboard a core activity; handwriting is outside the scope.
- Include graphics showing Korean encountered in real life, such as menus, with an option to read the text.
- Allow selection of a single word within Korean text for targeted help without automatically revealing the full answer.
- Provide a separate Anki-like flashcard function for repeated practice of difficult words.
- Give extra attention to remembering verbs and learning to conjugate them.
- Support personally relevant material across daily life and media, including Korean reels shared by the learner's wife. Menus and other everyday reading are core use cases.

The features and scope below are proposals from our discussion. Learner level, platform, and initial content are still open decisions. Writing uses keyboard input. The repository also imports Duolingo vocabulary and exports Anki decks. Preserve these workflows; themed sorting and shared vocabulary are planned integration points.

## How the areas connect

The five main areas are Themes, Real World Reading, Writing Notebook, Flashcards, and Verb Workshop.

For example, a learner opens a restaurant menu and saves an unfamiliar verb. They study its meaning, use it in a written sentence, and receive help with a past-tense mistake. Later, flashcards review the meaning while the verb workshop reviews the troublesome past-tense form.

Track vocabulary recall, conjugation performance, and writing practice separately. Show practical progress, such as being able to order a drink, alongside review performance.

## Maintaining the plan

Edit the document that owns the topic and update scope or open decisions when a choice changes. Keep confirmed requirements distinct from proposals. Research sources live with the learning framework; concrete examples live in the examples folder.
