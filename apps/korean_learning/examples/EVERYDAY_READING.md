# Everyday Korean Reading Examples

[Plan index](../PLAN.md)

Menus and other everyday Korean are core use cases. These proposed examples make the shared reading, vocabulary, writing, and review experience concrete across several situations.

| Situation | Reading goal | Optional typed practice |
| --- | --- | --- |
| Café or restaurant menu | Identify an item, its description, price, and available options | Write an order or a question |
| Subway or street sign | Identify a destination, exit, or direction | Write a short set of directions |
| Shop notice | Understand opening hours or a temporary closure | Write a reminder or question |
| Product label | Understand selected ingredients or preparation instructions | Write a shopping note or describe the item |
| Receipt | Identify items, quantities, and prices | Write a question about an item |
| Message or event poster | Understand what is happening, where, and when | Type a reply or invitation |

## Common experience

1. Open a curated visual scene or import a photo, screenshot, or pasted text.
2. Read the Korean in its original context, with a clear selectable transcript available.
3. Select an unfamiliar word or form and request only the help needed.
4. Complete the practical reading goal without automatically revealing the whole translation.
5. Optionally save selected words or forms to a relevant theme and review queue.
6. Optionally type a response using the language encountered.
7. Revisit the material later or try a different example from the same situation.

## Menu example

The learner opens a restaurant menu, finds a dish, checks its description and price, and selects an unfamiliar word for a hint. They can save that word to the restaurant collection and type an order using a familiar request pattern. A later session uses another menu to check whether the vocabulary is useful beyond the original layout.

Quick reading assistance is useful on its own. Review and writing remain available when the learner wants to study further.
