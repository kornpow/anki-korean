# Learning Framework

[Plan index](PLAN.md)

Proposed guiding principle: learn Korean through meaningful situations, practice recalling and using it, and revisit it with gradually less help. This is our product synthesis of several research ideas, not a single established theory or a validated method for this specific app.

### Balance four kinds of practice

Paul Nation's Four Strands framework distinguishes meaning-focused input, meaning-focused output, deliberate language study, and fluency development. It recommends roughly balanced time across these strands in a language course. We will use this as a coverage check across learning sessions, with flexible allocation for the learner's goals. See [Nation, The Four Strands, 2007](https://www.wgtn.ac.nz/lals/resources/paul-nations-resources/paul-nations-publications/publications/documents/2007-Four-strands.pdf).

| Strand | Application in this tool |
| --- | --- |
| Meaning-focused input | Read a menu or message to understand something useful |
| Meaning-focused output | Type an order, reply, or personal account to communicate meaning |
| Deliberate language study | Study vocabulary, spelling, particles, and conjugation patterns |
| Fluency development | Revisit familiar text and writing tasks to use known language more smoothly |

Reading material should be manageable enough to follow its message. Simplified scenes can prepare learners for denser authentic examples. Familiar-material practice should add little new language; faster keyboard use alone is not evidence of better language knowledge.

### Use situations to organize vocabulary

Prefer collections such as “ordering lunch,” combining a few foods with ordering verbs, quantities, and requests. Avoid introducing many easily confused category neighbors together by default. An experimental study found different outcomes for semantic clustering and situational thematic clustering; this motivates our content rule but does not establish that every themed list is better for every learner. See [Tinkham, 1997](https://journals.sagepub.com/doi/10.1191/026765897672376469).

### Retrieve and revisit

Repeated retrieval improved delayed foreign-vocabulary recall in Karpicke and Roediger's experiment. Our application is to ask learners to recall or type an answer before revealing it, and to keep reviewing items after an initial success. See [Karpicke and Roediger, 2008](https://pubmed.ncbi.nlm.nih.gov/18276894/).

Spacing research shows that review timing affects later retention and that a useful interval depends on the intended retention period. Our application is to revisit items across days as well as within a difficult-word session. These findings do not prescribe an exact app scheduler. See [Cepeda and colleagues, 2008](https://digitalcommons.usf.edu/psy_facpub/1766/).

### Provide help in small steps

Our proposed scaffolding rule is to offer the smallest useful hint and let the learner request more. Help for one selected word must leave the rest of the phrase untranslated. Record whether an answer was independent, hinted, or revealed, so assisted success is not treated as unaided recall. Help remains available; fading support means offering less by default as performance improves, not withholding assistance.

### Practice patterns and check their use

For verbs, connect meaning, dictionary form, stem, ending, and use in a sentence. Teach a pattern with worked examples, practice it on appropriate verbs, and later check it in a new sentence. Track meaning recall and conjugation separately. These are proposed design rules to test, rather than claims that one successful drill demonstrates general mastery.

### Define progress through independent use

Use a recurring cycle: encounter a meaningful situation, attempt understanding, request targeted help, type a response, receive feedback, then revisit after a delay in a changed context. The learner can enter through a themed lesson or a standalone practice mode.

For each word or pattern, distinguish recognition, typed recall, sentence use, and delayed performance. Prefer progress claims supported by repeated independent attempts and use in a new example. Track hint use and error type alongside correctness; measure typing speed separately.

Each collection should specify a practical communication goal, target vocabulary and patterns, a reading task, a typed output task, available hints, delayed review, and a new-context check. Evaluate whether learners remember and use the language later, not only whether they complete the collection. Exact mastery thresholds, scheduling, and hint order remain design hypotheses to validate.
