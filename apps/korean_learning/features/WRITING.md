# Keyboard Writing Practice

[Plan index](../PLAN.md)

Writing means typing Hangul using a Korean keyboard or input method. This applies to notebook entries, flashcard answers, and verb exercises. Input should allow syllable composition to finish before checking an answer.

Writing should progress from supported practice to personal expression:

1. Complete a sentence using the collection's vocabulary.
2. Write a sentence from a prompt.
3. Write several sentences about your own life.
4. Revisit an earlier entry using newly learned vocabulary.

A guided notebook could offer a word bank and one or two sentence patterns, with hints that can be hidden.

Proposed feedback should identify spelling, particle, and conjugation problems; offer a hint before a correction; and explain corrections briefly. Distinguish actual errors from optional improvements in naturalness. Let the learner revise their own work and save useful corrected phrases for review.

Unknown words encountered while writing can be added to the relevant theme. A missed verb form can be added to verb practice separately from the verb's meaning.

Handwriting, drawing surfaces, and handwriting recognition are outside the scope. Optional keyboard layout guidance may help learners who are still learning to type Hangul. The feedback implementation remains undecided.
